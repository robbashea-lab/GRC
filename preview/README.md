# Isolated dashboard preview

Run `npm run build` from the repository root to build the chat preview.
The preview runner explicitly enables `REACT_APP_PREVIEW=true` and clears the
backend URL. The login page offers one Sign In button with no credentials.
It opens the existing Platform Portfolio and client dashboards as Preview Admin.

The preview adapter initializes a shared sessionStorage store from synthetic
fixtures generated by the existing backend seed and GET endpoints. It never contacts Emergent, Railway, or a live
API. Entry persists in this browser until logout. This is a demo entry marker,
not a real account session. CRUD, review/finding/task/risk transitions, policy approval/verification, vendor
review scheduling, contacts, evidence and onboarding mutate that store. Derived
portfolio and client summaries are recalculated from its records. Onboarding
drafts autosave per client; finalization is idempotent. Reset Demo confirms before
restoring samples. Storage failures reject a save rather than losing it silently.

Invitations and notifications are explicitly simulated; no messages are sent.
Evidence is limited to 1 MB per file and the browser session storage quota.
Uploaded demo evidence can be downloaded and deleted. CSV exports use temporary
records. Board PDF generation and password/authentication setup require a real
backend and are explicitly unavailable. Unknown actions fail without pretending
to save. This demo is not a substitute for real authorization testing.

Regenerate fixtures using the dependencies in `preview/requirements.txt`:
`python preview/generate-fixtures.py`. The generator uses an isolated in-memory
database and does not load environment files or capture operational records.

Normal frontend `build` and `start` scripts retain the real authentication flow
when REACT_APP_PREVIEW is unset. They require REACT_APP_BACKEND_URL configured
for an actual backend. Backend authentication and tenant authorization are
unchanged. Do not enable preview mode when testing real authentication or data
persistence.
