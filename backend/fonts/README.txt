LiberationSans-Regular.ttf and LiberationSans-Bold.ttf are unchanged copies
of the fonts distributed with the Codex bundled pdfjs-dist/standard_fonts
runtime (bundle 26.1009.11318). Their SIL Open Font License 1.1 and copyright
notices are retained in LICENSE_LIBERATION. These fonts are embedded in
framework report PDFs so Latin, Greek and Cyrillic text does not depend on
the server's installed system fonts.
