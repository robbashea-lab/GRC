## Continuous new Review correction

Hosted testing of 67e088d found that raising a Risk from a Finding under a newly created Review reported an unconfirmed parent refresh. Native Review creation intentionally keeps the saved record inside the open drawer while the register's selected row remains empty. The new command's register guard incorrectly required an existing selected row. Reopening that saved Review and checking its existing Risk link succeeded, including reload; no creation retry or repair was used.

The correction accepts this existing open-new-editor state while retaining a same-client check for any selected row and every child identity, authority, mounted-context, route and accepted-load fence. It does not promote the new Review into the selected row or change the original save callback, which would reset the native form and its drafts.
