# NIST CSF 2.0 research and implementation basis

Researched 2026-09-22. Version: CSF 2.0, NIST CSWP 29, February 26, 2024.

Primary sources actually reviewed:

- https://nvlpubs.nist.gov/nistpubs/CSWP/NIST.CSWP.29.pdf — sections 1–4, Appendix A Core and Appendix B Tiers.
- https://www.nist.gov/cyberframework/profiles — organizational profile purpose and current/target comparison.
- https://doi.org/10.6028/NIST.SP.1301 — February 2024 Organizational Profiles Quick-Start Guide, introduction and scope guidance.
- https://www.nist.gov/cyberframework/informative-references — provenance, partial overlap and limits on NIST endorsement of external mappings.

Appendix A is the identifier authority: 6 Functions, 22 Categories, 106 Subcategories. Preserve nonconsecutive identifiers (for example ID.AM-07/08, PR.DS-10/11, DE.CM-06/09, RS.AN-03/06/07/08). The catalog uses concise original implementation prompts, category-specific evidence examples, and a source link on every outcome. Examples are not prescribed artifacts.

CSF outcomes do not prescribe an implementation method or fixed Review cadence. Nine suggested governance Reviews and 17 policy-area mappings are Omnisciente implementation recommendations, not NIST mandates. A documented policy is supporting evidence, not automatic outcome achievement. Obligations imposed by separate contracts or regulations must be assessed separately.

Current Profile uses existing authoritative assessment state and narrative. Target membership, intended outcome, priority and gap rationale are explicit per-outcome decisions. No default target, automatic gap score, certification claim, or state propagation is added. One client-wide profile pair is supported in this iteration. Multiple scoped profiles and optional contextual Tiers are deliberately deferred rather than inferring a Tier from assessment counts. Tier 4 is not assumed to be every organization's goal.

The current NIST website includes newer draft AI guidance; it does not replace the stable 2.0 Core used here. The old tool link redirects to a filters page; the published CSWP Appendix A remains the catalog authority. Informative mappings are separately labeled original partial implementation interpretations, not official NIST crosswalks. No SP 800-53 assessment is copied into this workspace.
