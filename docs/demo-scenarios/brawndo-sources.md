# Brawndo canonical content: scope and sources

This module supplies fictional current content, not records or proof of executed workflows. It is limited to Brawndo CIS v8.1 IG1. Native services own identities, dates, decisions, versioned interviews, Findings, Actions, evidence bytes and recurrence. No other client, installer or shared catalog is changed by this module.

`BRAWNDO_SCENARIO_PROFILE` describes 65 staff, two production lines, one warehouse, 55 office Windows devices, 10 shared Windows kiosks, 12 network devices and two Windows ERP/production VMs. The spreadsheet remains the authoritative asset register even though Intune manages endpoint settings. Six kiosk rows lack required identifiers/ownership; endpoint management and complete asset governance are different facts.

`brawndoSafeguardContent(definitionId, status)` returns nine plain strings: `scope`, `current_implementation`, `technology_process`, `assessment_notes`, `owner_role`, `process_owner_role`, `evidence_check`, `remediation`, `assessment_plan`. The caller must supply the canonical current status. Unknown IDs, out-of-scope safeguards and contradictory statuses throw. Returned objects can be edited without modifying the module. Role labels are business context for the coordinator to map to existing eligible actors/contacts; they create no account, permission or assignment.

The 56 current statuses derive from the native IG1 population: 48 addressed, four partial (1.1/3.1/7.2/15.1), two known failures (4.1/7.1) and two genuinely unassessed (11.4/14.8). Implementation is 48/56, approximately 85.7%, only if the integrated records have those actual states. This file does not set a score or dashboard total.

All assessed descriptions are authored synthetic scenario observations, not activities performed by the agent or a real customer. `evidence_check` specifies the small fictional artifact content the integrator should supply and reconcile. It is not an upload claim. Every known gap has a concrete remediation narrative. The unassessed items have no assessment notes, completed answers, remediation conclusion or verification claim; they have context and a first-assessment plan.
