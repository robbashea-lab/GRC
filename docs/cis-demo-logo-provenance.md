These local assets identify only the exact authorized Demo client identities. They do not change the GoverNara application brand or any customer-supplied logo. Brawndo retains its existing approved inline lightning artwork unchanged.

The four new SVGs are **locally authored compact redrawings of verified identities**, not official downloaded logo masters or claims of pixel-exact studio artwork. Their sources establish the fictional on-screen identities. Small details and type shapes are simplified to fit the existing avatar/container without changing surrounding typography or geometry.

References checked2026-10-21. No runtime hotlinks, third-party scripts, external fonts or remotely fetched SVGs. Local SVGs contain only svg/rect/g/path/text/circle primitives and safe literal attributes. XML/active-content checks are covered by ClientIdentityMark.test.jsx; actual browser image loading, small-size legibility and both locations must also be checked in the integrated candidate.

ClientIdentityMark checks trusted Demo adapter mode, authenticated Demo identity and authorized Org client membership with exact canonical client IDs and Demo metadata. Names and URL strings never select entertainment artwork. Standard signed-in mode, unauthorized cohort, missing identity, loading/error and unknown IDs retain the existing initial fallback. Failed local images also fall back to the initial. Images are decorative because the surrounding client name remains visible and accessible.

Existing client.logo_url form support is untouched; this rollout does not introduce loading arbitrary customer URLs. Avatar wrappers/CSS sizes remain unchanged. Safe system font fallback is used inside the four new marks; these are not exact proprietary typeface reproductions.
