## Activation and authority

- **M**: always-active substantive question that must be answered for a complete reported interview of the selected native control. It does not mean all Annex A controls are mandatory or that the exact prompt is a verified ISO requirement.
- **C**: context gate or follow-up activated by that specific gate. This is an authored inquiry boundary for an actual subpart, not a normative exemption.
- **G**: original practical guidance. All substantive M/C questions are G in authority. Optional text is G only and cannot determine implementation status.
- **W**: `working_interpretation`; topic and represented edition are supported, but full exact Annex A statements, qualifiers and completeness still need authorized comparison.

Each row identifies `ISO27001:2022:<native ID>` as the intended licensed comparison target, not as accessed normative text. R01 and R02 resolve to that same native control. N01 identifies related NIST guidance only. I01/I02 establish version identity for all rows, never the prompt's exact obligation. Every JSON question also carries its own `source_refs` array.

Native SoA remains the sole whole-control applicability workflow. This content has no whole-control N/A choice and does not infer SoA, native implementation status, evidence validity, assessment dates or audit results. Every control retains unconditional substantive questions. Mandatory ISMS clauses are outside this part and cannot be hidden by its conditions.

Context choices are exactly `Relevant`, `Not relevant here`, `Not sure`. The engine must require a reason in the corresponding detail field for `Not relevant here`, hide only explicitly dependent follow-ups, and retain `Not sure` as unresolved. A hidden historical branch cannot establish effectiveness or exclude the whole control. Providers and outsourced activities remain relevant where they support the scope; outsourcing alone is not an exclusion. These are integration contracts for the main agent's engine/adapters, not behavior implemented by this content file.

Select choices are exactly `Yes`, `Partially`, `No`, `Not sure`. Optional owner/source/tool text cannot affect status when omitted or uncertain. Not knowing an owner's name differs from not assigning responsibilities. Help examples and alternatives are nonexclusive guidance, not mandatory products, titles, artifacts, exact frequencies or legal deadlines.
